# Legacy reference only

This Python package is the recovered v0.1 rescue implementation. It remains in the active tree only until the Java/Sites MVP-1 real-WS and production-shape smoke gates pass.

Allowed use:

- recover verified v0.1 behavior;
- derive protocol and state-machine tests;
- inspect known MVP-A/MVP-B evidence.

Forbidden use:

- copying the Python package structure into a new module;
- carrying Kanban, Hermes Plugin, bare approval, SSH forced-command, Runtime Session, or WS-specific fields into the new Service domain;
- treating this package as the current target design.

See `doc/asset-inventory.md` and `doc/history/v0.1-rescue/`.
