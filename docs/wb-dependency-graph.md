## 4. 无环校验规则

需求只能依赖更早波次，或同波次中明确写出的串行前项；不得让实现需求反向成为其合同、Gate 0 或仓库治理的前置。新增边必须先做拓扑校验。为制造并发而省略真实前置，视为“假并发”并拒绝进入计划。
