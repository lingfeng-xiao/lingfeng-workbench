## 4. 无环校验规则

恢复/GitHub、Sites Gate 0、产品合同三线从最早波次独立推进。需求只能依赖本线更早节点，或真实的跨线交汇点；不得让 GitHub/Codex 基础设施成为 Sites 现状回读或产品合同设计的伪前置，也不得让实现需求反向成为合同、Gate 0 或仓库治理的前置。新增边必须先做拓扑校验。人为等待和省略真实前置都属于“假并发”。
