# v0.2.0-mvp1-rc1 冻结说明

这是三模块架构的第一个仓库级冻结候选，不是生产发布授权。

## 包含

- 权威架构、资产清单、ADR、Client API v1 和 Node Protocol v1。
- Java 21 / Spring Boot 3.5.5 的 `workbench-service` 与 `workbench-node`。
- 绑定既有 Private Site、D1/R2 为 `null` 的只读 `workbench-web`。
- fake Runtime 完成闭环、Service 重启恢复、Web 一致性和敏感数据边界证据。
- Windows `ws.cmd` 单行 prompt 修复及对应测试。

## 冻结边界

- Hermes 仍是外部客户端，Kanban 不进入目标设计。
- Service 只保存最小控制数据；完整 Runtime 证据只在 Node。
- 三模块不共享 DTO、Entity、数据库或源码模块。
- Interaction 精确恢复仍属于 MVP-2。

## 未满足 Gate

- 真实 WS 当前无输出，未完成可信终态验收。
- 未做个人服务器生产形态 smoke、Sites 发布或公司电脑安装。
- 旧 Python、冻结 PR/分支和旧 Sites D1 仍保留，未进入删除 Gate。
